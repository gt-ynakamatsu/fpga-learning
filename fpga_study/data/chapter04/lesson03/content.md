# 順序回路パズル：Dフリップフロップで記憶しよう

## このパズルについて

**Dフリップフロップ（D-FF）** を使って、クロックのたびに入力 D の値を記憶する回路を作ります。

### D-FF の動作

- 入力 D: 次のサイクルで記憶する値
- 出力 Q: 現在の記憶値（前のクロックエッジで確定した値）
- クロックが↑のとき: Q ← D（Dの値をQに記録）

---

## パズルの操作方法

1. ツールバーの「DFF」ボタンをクリックしてキャンバスに追加
2. 入力 D を D-FF の D ポートに配線
3. D-FF の Q ポートを出力に配線
4. **「Clock ↑」** ボタンを押してクロックを1回進める
5. Q の値が変化することを確認
6. 「⚡ 回路を確認」で全クロックサイクルの動作を採点

---

## 目標の動作（クロックごとの状態）

| クロック回数 | D の入力 | Q（出力） |
|------------|---------|----------|
| 初期状態    | 1       | 0 ← 最初は 0 |
| 1回目 ↑    | 1       | 1 ← D=1 を記憶 |
| 2回目 ↑    | 0       | 1 ← 前の記憶 |
| 3回目 ↑    | 0       | 0 ← D=0 を記憶 |

D-FF はクロックの瞬間の D を記憶します。クロックエッジ後に D が変わっても Q はそのまま。

---

## 下のパズルエディタで試してみましょう！

「Clock ↑」ボタンを押すたびに1クロック分進みます。右の表で現在のクロック回数と期待値を確認しながら動作を確認してください。
