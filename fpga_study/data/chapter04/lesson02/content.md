# リセットとカウンタ

## リセット信号

デジタル回路を最初の状態（0）に戻すのが**リセット（RST）**信号です。

### 同期リセットと非同期リセット

| 種類 | タイミング | 特徴 |
|------|----------|------|
| **同期リセット** | クロックのエッジのとき | 予測しやすい、タイミング設計が楽 |
| **非同期リセット** | RST信号が変化したとき | 即座にリセット |

FPGAでは一般的に**同期リセット**が推奨されます。

### 同期リセット付きDフリップフロップの動作

```
クロック↑ のとき:
  もし RST=1 なら Q ← 0 (リセット)
  そうでなければ Q ← D
```

## カウンタ

**カウンタ** はクロックのたびに値が増える回路です。

### 4ビットカウンタの動作

```
CLK:   ↑   ↑   ↑   ↑   ↑   ↑   ...
Count: 0   1   2   3   4   5   ...
```

0から順番に増え、15（2進数: 1111）まで行くと次は0に戻ります。

### カウンタの内部構造

4ビットカウンタは、現在の値に1を足してフリップフロップに記憶します。

```
Q[3:0] ──→ [+1加算器] ──→ D[3:0]
              ↑
            CLK（クロックの度に更新）
```

---

## 利用例：タイマー

100MHzのクロック（1秒に1億回）でカウントすると：

- 1億回カウント = 1秒
- カウント値が1億になったら「1秒経過」と判定してリセット

これで**タイミング制御**ができます。LEDを1秒ごとに点滅させるなどの用途に使います。

---

## プリセット値を持つカウンタ

特定の値からカウントを始めたり、特定の値でリセットしたりもできます。

例：0〜9のカウンタ（10進カウンタ）

```
9 → 0 → 1 → 2 → ... → 9 → 0 → ...
```

---

## まとめ

- リセット: 回路を初期状態に戻す信号
- 同期リセット: クロックエッジで RST を確認（FPGAで推奨）
- カウンタ: クロックごとに +1 する回路
- 上限値でリセットすることで任意の周期のカウンタが作れる
