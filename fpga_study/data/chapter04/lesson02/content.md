# リセットとカウンタ

## リセット信号

デジタル回路を最初の状態（0）に戻すのが**リセット（rst）**信号です。

### 同期リセット（この教材での標準）

この教材では、**同期リセット・正論理（rst）** を標準として使います。

- **同期**: クロックの立ち上がりエッジのタイミングで処理する
- **正論理（rst）**: rst=1 のときリセット状態（0）になる

```systemverilog
always_ff @(posedge clk) begin
    if (rst)   q <= 1'b0;  // リセット（clkに同期）
    else       q <= d;     // 通常動作
end
```

クロックに同期しているため、タイミングの設計がしやすく、FPGAで扱いやすい方式です。

## カウンタ

**カウンタ** はクロックのたびに値が増える回路です。

### 4ビットカウンタの動作

| クロック↑ | count の値 |
|----------|-----------|
| 初期（rst=1）| 0 |
| 1回目     | 1 |
| 2回目     | 2 |
| 3回目     | 3 |
| …        | … |
| 15回目   | 15 |
| 16回目   | 0（くり返し）|

0から順番に増え、15（4ビットの最大）まで行くと次は0に戻ります。

### カウンタの内部構造

4ビットカウンタは、現在の値 `count[3:0]` に1を足して、クロックのたびにフリップフロップに記録します。

```
現在のcount[3:0]
    │
    ↓
 [+1 加算器]
    │
    ↓
 count + 1  ← D入力
    │
 [4ビットFF]  ← clk
    │
    ↓
count[3:0] ← Q出力（次のクロックまで保持）
```

（加算器の出力をフリップフロップのD入力に繋ぎ、Q出力を次のD計算にも使います）

---

## 利用例：タイマー

100MHzのクロック（1秒に1億回）でカウントすると：

- 1億回クロックが刻む = 1秒
- カウンタを0から始めて **99,999,999** に達したら次のクロックでリセット（0に戻す）
- 0 〜 99,999,999 で100,000,000通り = ちょうど1秒分

```
カウンタ: 0 → 1 → 2 → ... → 99,999,999 → 0 → 1 → ...
                                   ↑ここでリセット（1秒経過）
```

---

## まとめ

- 同期リセット（rst=1 でリセット）: クロックに同期するため設計しやすい
- カウンタ: クロックごとに +1 する回路
- 上限値でリセットすることで任意の周期のカウンタが作れる
- 100MHzで1秒タイマー: 0〜99,999,999 をカウントしてリセット
