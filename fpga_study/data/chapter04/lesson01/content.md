# クロックとフリップフロップ

## 組み合わせ回路の限界

これまでの組み合わせ回路は、入力が決まれば即座に出力が変わります。しかし「前の状態を覚えておく」ことができません。

電子機器には「昨日の状態から続ける」「カウントアップする」など、状態を記憶する機能が必要です。これを実現するのが**順序回路**です。

---

## クロック信号

**クロック（CLK）** は一定の周期で 0→1→0→1... と繰り返す信号です。

```
CLK: 0  1  0  1  0  1  0  1 ...
     ↑  ↑  ↑  ↑  ↑  ↑  ↑  ↑
    立ち上がりエッジ（0→1 の瞬間）
```

- **立ち上がりエッジ（↑）**: 0→1 に変わる瞬間
- **立ち下がりエッジ（↓）**: 1→0 に変わる瞬間

デジタル回路の動作は多くの場合、クロックの立ち上がりエッジに同期して行われます。

---

## Dフリップフロップ（D-FF）

**Dフリップフロップ** は最も基本的な記憶素子です。

- 入力: D（Data）
- 出力: Q（現在の記憶値）
- クロック: CLK

**動作**: クロックの立ち上がりエッジが来た瞬間の D の値を記憶し、Q として出力し続ける。

### 動作の例（立ち上がり直前の D と直後の Q）

| クロック↑ | 直前のD | 直後のQ | 説明 |
|---------|--------|--------|------|
| 初期     | -      | 0      | リセット直後 |
| 1回目↑  | 1      | 1      | D=1 を記憶 |
| 2回目↑  | 1      | 1      | D のまま（記憶を保持）|
| 3回目↑  | 0      | 0      | D=0 を記憶 |

> **ポイント**: クロックのエッジ以外では D が変わっても Q は変わりません。「クロックが来たその瞬間の D を記憶する」のです。

---

## フリップフロップの回路記号

```
     D ─┤       ├─ Q
        │  D-FF │
    CLK ─┤  CLK │（三角記号がエッジトリガを示す）
        └───────┘
```

CLK の入力には三角形の記号が付きます（エッジトリガを示す）。

---

## まとめ

- 順序回路は状態を記憶できる
- クロックは一定周期で変化する同期信号
- Dフリップフロップ: CLK の立ち上がりで D を Q に記録
- クロックの外では D が変わっても Q はそのまま（記憶保持）
