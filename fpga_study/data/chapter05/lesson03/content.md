# ステートマシンの設計演習

## 演習：簡易自動販売機

**仕様**:
- 商品の値段は 2 コイン（1コイン = 10円とし、20円の商品）
- 入力: COIN（コインが入った = 1）
- 出力: VEND（商品を出す = 1）
- コインは1回に1枚ずつ入れる

---

## ステップ1：状態を洗い出す

| 状態 | 意味 | 投入済みコイン |
|------|------|-------------|
| S0   | 待機  | 0枚         |
| S1   | 1枚  | 1枚投入済み  |
| S2   | 排出  | 2枚（商品排出）|

---

## ステップ2：状態遷移図

```
            COIN=1                COIN=1
[S0: 0枚] ──────→ [S1: 1枚] ──────→ [S2: 排出]
    ↑ COIN=0(自己)   ↑ COIN=0(自己)         │
    └────────────────────────────────────────┘
                  （商品排出後は S0 に戻る）
```

出力 VEND=1 になるのは S2 の状態のみ（ムーア型）。

---

## ステップ3：状態エンコード

3状態 → 2ビット必要

| 状態 | エンコード (S1, S0) |
|------|-----------------|
| S0   | 00              |
| S1   | 01              |
| S2   | 10              |

---

## ステップ4：次状態ロジック

| 現状態 (Q1,Q0) | COIN | 次状態 (D1,D0) |
|--------------|------|--------------|
| 00 (S0)      | 0    | 00 (S0)      |
| 00 (S0)      | 1    | 01 (S1)      |
| 01 (S1)      | 0    | 01 (S1)      |
| 01 (S1)      | 1    | 10 (S2)      |
| 10 (S2)      | 0    | 00 (S0)      |
| 10 (S2)      | 1    | 00 (S0)      |

---

## ステップ5：論理式

真理値表をカルノー図で整理すると：

**D0（次状態の下位ビット）**:
- D0 = 1 になるのは: Q0=0, Q1=0, COIN=1 → S0→S1 のとき
- D0 = (NOT Q1) AND (NOT Q0) AND COIN

**D1（次状態の上位ビット）**:
- D1 = 1 になるのは: Q0=1, Q1=0, COIN=1 → S1→S2 のとき
- D1 = (NOT Q1) AND Q0 AND COIN

**VEND（出力）**:
- VEND = Q1（S2 状態のとき）

---

## 実装イメージ（SystemVerilog風）

```systemverilog
module vending_machine(
  input  logic clk, rst_n, coin,
  output logic vend
);
  // 状態エンコード
  typedef enum logic [1:0] {S0=2'b00, S1=2'b01, S2=2'b10} state_t;
  state_t state;

  // 次状態ロジック
  always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) state <= S0;
    else case (state)
      S0: state <= coin ? S1 : S0;
      S1: state <= coin ? S2 : S1;
      S2: state <= S0;      // 商品排出後は待機へ
    endcase
  end

  // 出力ロジック（ムーア型）
  assign vend = (state == S2);
endmodule
```

## まとめ

ステートマシン設計の5ステップ：

1. 状態を洗い出す
2. 状態遷移図を書く
3. 状態をエンコードする
4. 次状態ロジックの真理値表を作る
5. 論理式・回路を実装する
