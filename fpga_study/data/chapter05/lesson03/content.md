# ステートマシンの設計演習

## 演習：簡易自動販売機

**仕様**:
- 商品の値段は 2 コイン（1コイン = 10円とし、20円の商品）
- 入力: COIN（コインが入った = 1、1クロック間だけ1になるパルス信号）
- 出力: VEND（商品を出す = 1）
- コインは1回に1枚ずつ入れる
- S2（排出）状態では、コインが来ても S0 へ戻る（コインを受け付けない）

---

## ステップ1：状態を洗い出す

| 状態 | 意味 | 投入済みコイン |
|------|------|-------------|
| S0   | 待機  | 0枚         |
| S1   | 1枚  | 1枚投入済み  |
| S2   | 排出  | 2枚（商品排出）|

---

## ステップ2：状態遷移図

```
           COIN=1               COIN=1
→[S0:0枚] ────→ [S1:1枚] ────→ [S2:排出]
   ⟳ COIN=0        ⟳ COIN=0         │
                                     │（排出後 → S0）
                 ←─────────────────┘
```

出力 VEND=1 になるのは S2 の状態のみ（ムーア型）。

---

## ステップ3：状態エンコード

3状態 → 2ビット必要

| 状態 | エンコード (Q1, Q0) |
|------|-----------------|
| S0   | 00              |
| S1   | 01              |
| S2   | 10              |

（11 は未使用状態。ドントケア扱い）

---

## ステップ4：次状態の真理値表

| Q1 | Q0 | COIN | 次状態 | D1 | D0 |
|----|-----|------|--------|----|----|
| 0  | 0   | 0    | S0(00) | 0  | 0  |
| 0  | 0   | 1    | S1(01) | 0  | 1  |
| 0  | 1   | 0    | S1(01) | 0  | 1  |
| 0  | 1   | 1    | S2(10) | 1  | 0  |
| 1  | 0   | 0    | S0(00) | 0  | 0  |
| 1  | 0   | 1    | S0(00) | 0  | 0  |
| 1  | 1   | -    | DC（ドントケア）| - | - |

---

## ステップ5：論理式

真理値表から論理式を導きます。

**D1（次状態の上位ビット）**:
D1 = 1 になるのは: Q1=0, Q0=1, COIN=1 → S1→S2 のとき

- D1 = (NOT Q1) AND Q0 AND COIN

**D0（次状態の下位ビット）**:
D0 = 1 になるのは:
- Q1=0, Q0=0, COIN=1 → S0→S1
- Q1=0, Q0=1, COIN=0 → S1→S1（1枚のまま待機）

真理値表を見ると、D0=1 になる条件は「Q1=0 かつ (Q0と COIN が異なるとき)」です：

- **D0 = (NOT Q1) AND (Q0 XOR COIN)**

確認（Q1=0 の場合のみ）:
- Q0=0, COIN=0 → 0 XOR 0 = 0 → D0=0 ✓（S0→S0）
- Q0=0, COIN=1 → 0 XOR 1 = 1 → D0=1 ✓（S0→S1）
- Q0=1, COIN=0 → 1 XOR 0 = 1 → D0=1 ✓（S1→S1）
- Q0=1, COIN=1 → 1 XOR 1 = 0 → D0=0 ✓（S1→S2）

**VEND（出力）**:
- VEND = Q1（S2 状態のとき）

---

## 設計まとめ

ステートマシン設計の5ステップ：

1. 状態を洗い出す
2. 状態遷移図を書く
3. 状態をエンコードする
4. 次状態ロジックの真理値表を作る
5. 論理式・回路を実装する

第6章では、このような回路を SystemVerilog でコードとして記述する方法を学びます！
