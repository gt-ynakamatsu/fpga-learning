# ステートマシンとは？

## ステートマシン（有限状態機械）の概念

**ステートマシン**（Finite State Machine, FSM）は、有限個の「状態」を持ち、入力に応じて状態を遷移していく仕組みです。

デジタル回路設計でとても重要な概念で、複雑な制御ロジックをわかりやすく設計できます。

---

## 身近な例：信号機

信号機を考えてみましょう。

**状態**: 青、黄、赤

**遷移規則**:
- 青 → 一定時間後 → 黄
- 黄 → 一定時間後 → 赤
- 赤 → 一定時間後 → 青

```
→[青] ──→ [黄] ──→ [赤]
   ↑                  │
   └──────────────────┘
```

（→は初期状態を示す矢印。この例では「青」が最初の状態です）

これがシンプルなステートマシンです！

---

## ステートマシンの3要素

1. **状態（State）**: 回路が現在「どのモードにいるか」
2. **入力（Input）**: 状態を変化させる信号
3. **遷移（Transition）**: ある状態から別の状態への移り方

（出力は状態や入力から決まります）

---

## 状態遷移図

ステートマシンは「状態遷移図」で表現します。

- **丸**: 状態
- **矢印**: 遷移（条件付き）
- **入ってくる矢印（入り口のない矢印）**: 初期状態

例：ボタンを1クロック間 btn=1 にするたびにON/OFFが切り替わる回路

```
         btn=1              btn=1
→[S0:OFF] ────→ [S1:ON]⟳（btn=0で自己遷移）
   ⟳                │
（btn=0で自己遷移）   │ btn=1
                    └──→ [S0:OFF]
```

（→はそこから入ってくる矢印が無い方向を示し、最初の状態を表します）

整理すると:

| 現在の状態 | 入力 btn | 次の状態 |
|-----------|---------|---------|
| S0 (OFF)  | 0       | S0 (OFF) |
| S0 (OFF)  | 1       | S1 (ON)  |
| S1 (ON)   | 0       | S1 (ON)  |
| S1 (ON)   | 1       | S0 (OFF) |

---

## デジタル回路での実装

ステートマシンは以下の要素で実装します：

1. **状態レジスタ**: 現在の状態を記憶するフリップフロップ
2. **次状態ロジック**: 入力と現在の状態から次の状態を計算する組み合わせ回路
3. **出力ロジック**: 状態（と入力）から出力を計算する組み合わせ回路

---

## まとめ

- ステートマシンは有限個の状態と遷移規則を持つ
- 信号機・自動販売機・通信プロトコルなど広く使われる
- 状態遷移図で視覚的に設計できる
- 初期状態は「入ってくる矢印（起点のない矢印）」で示す
