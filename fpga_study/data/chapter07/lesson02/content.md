# 波形を読む — カウンタの演習

## 波形ビューアの見方

シミュレーション後に生成される VCD ファイルを波形ビューアで表示すると、各信号の時系列変化をグラフで確認できます。

```
時間(ns): 0   10   20   30   40   50   60   70   80
clk:      ╔╗  ╔╗   ╔╗   ╔╗   ╔╗   ╔╗   ╔╗   ╔╗
rst:      ████████╗                               ↑リセット解除
count:    ══0════╗══1══╗══2══╗══3══╗══4══╗══5══
```

- **clk**: クロック（規則的に0→1→0→1と変化）
- **rst**: リセット信号（1のあいだ count=0 になる）
- **count**: カウンタ値（クロックごとに +1）

---

## 波形の読み方のポイント

1. **立ち上がりエッジ（↑）** でFFが更新される
2. **リセット中（rst=1）** は count が 0 のまま
3. リセット解除後、次のクロックから **カウントアップ** 開始
4. 多ビット信号（count[3:0]）は数値として表示される

---

## 演習：4ビットカウンタを実装しよう

### 仕様

- 入力: clk（クロック）, rst（同期リセット、rst=1 でリセット）
- 出力: count[3:0]（4ビットカウンタ、0〜15）
- rst=1 のとき count=0
- それ以外はクロックごとに count が +1（15の次は0に戻る）

### テンプレート

```systemverilog
module counter4(
    input  logic       clk,
    input  logic       rst,
    output logic [3:0] count
);
    always_ff @(posedge clk) begin
        if (rst)
            count <= /* ここ */;   // リセット時
        else
            count <= /* ここ */;   // カウントアップ
    end
endmodule
```

- カウンタ: リセット時 0、それ以外は +1（4ビットは 0〜15 でくり返す）
