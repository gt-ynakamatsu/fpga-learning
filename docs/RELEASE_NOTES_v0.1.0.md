# リリースノート — v0.1.0

**リリース日**: 2026-10-20  
**タグ**: `v0.1.0`

---

## 概要

FPGAお勉強アプリ v0.1.0 — 完全初心者向けオフライン Web アプリの最初の公開版です。

FastAPI + Vanilla JS で構成された完全オフライン動作の学習環境です。Python の `pip install` 一発で起動でき、ブラウザから FPGA・デジタル回路の基礎を学べます。

---

## 収録内容

### 教材（全7章、すべて published）

| 章 | タイトル | 主な演習 |
|---|---|---|
| 第1章 | 2進数・16進数・情報の単位 | 練習問題・確認クイズ |
| 第2章 | 論理ゲートの基礎 | 練習問題・クイズ・回路パズル |
| 第3章 | 組み合わせ回路 | 練習問題・クイズ・回路パズル |
| 第4章 | 複合回路（MUX・デコーダ等） | 練習問題・クイズ・回路パズル |
| 第5章 | 順序回路・フリップフロップ入門 | 練習問題・クイズ |
| 第6章 | HDL 入門（ANDゲート・MUX・D-FF） | HDL 演習・クイズ |
| 第7章 | カウンタ設計 | HDL 演習・クイズ |

### 演習の種類

- **練習問題**: 数値・文字の入力問題、即時フィードバック
- **確認クイズ**: 4択問題、解説付き、per-attempt スコア管理
- **回路パズル**: ゲートをドラッグして配線する回路組み立て問題
- **HDL 演習**: SystemVerilog コードを書いてシミュレーション採点（deltasim 使用）

---

## 主な特徴

- **完全オフライン**: インターネット接続不要
- **進捗管理**: SQLite（`~/.fpga_study/progress.db`）に学習履歴を記録
- **バッジシステム**: レッスン完了・章マスターでバッジ取得
- **初心者向けエラー案内**: HDL エラーを日本語で説明（§11 仕様準拠）
- **deltasim 統合**: SystemVerilog シミュレーター deltasim v0.2.2 以上に対応

---

## システム要件

| 項目 | 要件 |
|---|---|
| Python | 3.10 以上 |
| OS | Windows / Linux / macOS |
| deltasim | 0.2.2 以上（HDL 演習に必要） |

### HDL 演習（deltasim のインストール）

```bash
pip install 'git+https://github.com/gt-ynakamatsu/deltasim.git@v0.2.2'
```

deltasim がインストールされていない場合、第1〜5章の練習問題・クイズ・回路パズルは引き続き利用できます。

---

## インストールと起動

```bash
pip install .
fpga-study
```

---

## 既知の制約

- 実ボード（FPGA 実機）との接続機能はありません
- HDL 採点は deltasim CLI 経由のシミュレーション結果に基づきます
- GitHub へのリポジトリ移行は別途対応予定
- E2E テスト（Playwright）は `pip install ".[dev]"` と `playwright install chromium` が必要
- `;` 抜けエラーの行番号は deltasim の仕様により次の字句の位置を指します
